# Packet A — Product Truth and State Integrity

Public Presence stores independent evidence for Google Search, Google Maps,
Bing, Apple Maps, DuckDuckGo, Yelp, Facebook, and Instagram. Legacy shared-
query records and legacy result-type labels normalize to the retained
destination evidence model with `legacy_imported` provenance.

Action Plan conclusions aggregate only reviewed primary destination observations:
Google Search, Google Maps, and Bing. Apple Maps and DuckDuckGo remain visible
supporting evidence but cannot create or weaken a primary conclusion. Public
Presence reports primary-check coverage separately from observed result quality;
it does not fabricate a numeric visibility score. A
prominent primary result mixed with a weak or absent primary result is explicitly
`mixed`, never reduced to a single destination conclusion. Untested destinations
neither improve nor reduce the conclusion. Aggregate confidence is the weakest
applicable provenance among reviewed primary observations, calculated in a
deterministic order.

AI Visibility contains manual AI Presence observations and qualitative AI/GEO
Readiness dimensions. It is intentionally excluded from numeric overall scoring,
checked counts, completion measures, and score-derived statuses. It has no
provider scan controls and no numeric AI score.
Raw responses remain separate from the operator’s interpretation.

Entity readiness and optional actual consumer-assistant observations live under
Profile Management. An untested assistant result is not a failed readiness
check. A public observation can seed one Profile Management projection with
preserved source/timestamp evidence, but never infers or replaces owner access.

Only a reviewed Consumer Observation counts as AI Presence; readiness alone is
not a platform test or coverage claim. Consumer assistant behavior is reported
only when a reviewed manual observation exists; listing/entity readiness is
otherwise reported separately.

Business Profile facts remain authoritative; destination evidence is never
merged into that profile automatically. Website manual evidence changes reset
its analysis timestamp and require fresh analysis while preserving server and
browser evidence records.

Readiness labels retain the concise Ready/Partial/Unable-to-verify vocabulary.
The UI identifies these as readiness states rather than provider-test results,
and clarifies that a Partial state can reflect a profile fact without public
source evidence. Detailed source labeling per readiness dimension remains a
later review-slice enhancement.
